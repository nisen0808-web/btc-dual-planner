# BTC 期权与双币收益对比

用同一笔资金、同一个目标价和同一个到期时间，比较卖出 BTC 期权能收多少权利金，以及申购双币能拿多少利息。打开网页即可查看各平台的公开报价，无需绑定交易账户。

## 怎么比

1. **选低买或高卖。** 想在目标价买入 BTC，选「低买 PUT」，比较卖出看跌期权和双币低买。已持有 BTC，愿意在目标价卖出，选「高卖 CALL」，比较卖出看涨期权和双币高卖。
2. **填投入、目标价和到期时间。** 投入可以用 USDT 金额或 BTC 数量填写。目标价和「距现价」百分比填一个，另一个会自动换算。低买默认向下，高卖默认向上。到期时间按新加坡时间显示。
3. **选权利金口径。** 想知道按当前买盘能卖出多少，选「买盘深度 · 即时参考」。页面从最高买价逐档计算，买盘接不下整笔时会提示深度不足。想估算自己挂单的收入，选「卖一挂价 · 成交后」，金额按整笔都在卖一价成交计算。
4. **选要比较的平台。** 「卖出期权」可选 Binance、OKX、Coinbase App（Deribit 盘口）或 Gate。「对比双币」可选 Binance、OKX、Gate 或 Bitget。两个下拉框可以分别选一家或「全部」。

例如，准备拿 **100,000 USDT** 在 **62,000** 接 BTC，可以选「低买 PUT」，填好这两个数，选定到期日，再选「买盘深度 · 即时参考」「全部期权」和「全部双币」。在结果里看各家期权按当前买盘能收多少，再看同一期双币能给多少。

## 怎么读结果

主表按**到期未触发**比较。低买时，双币到期没有接到 BTC；高卖时，双币到期仍持有 BTC。若触发，期权还涉及到期结算，双币则按产品规则兑换本金和利息，需另看到期结果。

| 页面指标 | 读法 |
| --- | --- |
| 本期净收入 | 期权看整笔权利金扣公开开仓费后剩多少；普通双币看这笔本金在本期产生的利息。两者都只列收益部分。 |
| 本期收益率 | 将本期收入除以对应投入本金。高卖期权按所投入 BTC 的市值计算。 |
| 简单年化 / 平台 APR | 期权按「本期收益率 × 365 ÷ 剩余天数」折算，剩余不足一天按实际时长计算。双币列平台公布的 APR。想知道这一单能拿多少钱，直接看「本期净收入」。 |
| 与对侧最高收入差 | 多平台比较时，期权行用本行净收入减去所选双币中最高的可比收入；双币行则减去所选期权中的最高值。正数表示本行多拿，负数表示少拿。 |

跨平台按相同数值的目标价匹配，各平台保留自己的计价币种与结算指数。跨币种金额按同期汇率折算。遇到未挂牌、锁盘、盘口不足或缺少可比汇率，对应栏会显示原因或「—」；仅有效报价参与排名。

两边各选一家平台，还可以展开费用与到期结算，核对盘口和保险成本。「保险怎么算」列出买入保护期权要付的权利金和开仓费，方便比较加保险后还剩多少收益。
