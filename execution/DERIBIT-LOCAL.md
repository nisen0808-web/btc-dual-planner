# Deribit USDC 本机执行

用户选择在当前 Windows 电脑运行。`start-local.ps1` 启动后台进程，绑定
`127.0.0.1:8788`；`/setup` 是本机账户配置入口。未输入凭据时没有任何私有
API 请求或交易能力。关闭网页不停止执行器；电脑必须保持开机、联网和不休眠。
停止执行器不会平仓，也不会取消交易所已经接受的订单。

## 连接

1. 默认环境是 Deribit 测试网，也可由用户本人选择主网并准备相应环境的专用子账户。
   首版支持 `segregated_sm`
   标准保证金，不支持跨币抵押或组合保证金；账户只使用 USDC 和已对账 BTC。
2. Key 只允许 `account:read trade:read_write wallet:none`，其他非必要权限关闭。
   `account:read_write`、钱包权限、未知范围、非子账户都会阻止执行。
3. 由用户本人在本机设置页输入所选环境的 Client ID / Client Secret。下单许可
   默认关闭，切换环境时重新关闭。勾选许可后仍只允许后续逐笔明确确认的订单；
   主网使用真实资金，保存设置不是提交订单。密钥不会进入远端 Site。
4. 点击配对。私有策略页面收到一个独立的本机会话，最长 8 小时、闲置 15 分钟
   失效；会话只保存在当前标签页会话存储，实际 API 密钥不进入浏览器存储。
5. 在策略页面检查服务器冻结的资金、数量、最低卖价和接币规则后，由用户本人
   逐笔最终确认。没有账户连接、明确下单许可或完整权限与余额核验时不能下单。

旧版本要求先有本执行器记录的测试网完整到期接币记录才能启用主网，这是开发时
设置的限制，不是 Deribit 的规定。现已按用户要求移除该历史记录门禁；主网凭据、
本机明确下单许可、账户鉴权与每笔最终确认仍分别要求，不会自动启用主网交易。

`list_api_keys` 可能受交易所 TFA/权限限制；未通过真实权限核验时不会显示可交易。
本轮未完成真实私有账户验证、测试网交易或真实到期验证。

## 安全和持久化

凭据用 Windows DPAPI CurrentUser 加密，运行数据存放在工作区
`work/deribit-execution`，不在站点源码或部署包里。DPAPI 依赖真实 Windows
用户 profile；工具沙箱中的模拟 profile 可能无法加解密。测试使用合成数据，
在真实用户上下文验证过往返；任何加密失败都不会退回明文保存。

服务校验 loopback socket、Host、精确 Site Origin、Bearer 配对凭证及 JSON 请求；
不开放任意 CORS、不使用跨站 Cookie、不使用公网隧道。设置接口仅本机同源
加随机 CSRF，页面禁止 iframe。配对可撤销，更新密钥或重启进程会撤销旧配对。
撤销网页配对不暂停已经确认的策略。

每个测试网/主网使用独立 SQLite 日志，策略绑定真实子账户 ID。先记日志再发单。
Deribit label 不是交易所幂等保证，超时、断线或重启后只按原标签核对近期和历史
订单及成交，原标签绝不重发。终态部分现货成交保留实际 BTC 和费用并等待处理。

到期核验官方交割价、期权事件及对应期货现金交割、完整资金流水、空持仓及两次
稳定现金观察后，才允许另买 BTC_USDC。上限是结算价乘确认缓冲，最多在到期后
五分钟内发送一次限价 IOC；不加杠杆、不追价、不补钱。手续费按账户 fixed/relative
折扣和当前合约规格核验；缺失 API cap 时明确使用官方 .125 费用政策上限。

## 已验证与未验证

已验证主网/测试网匿名公开合约及盘口、真实用户 DPAPI 合成数据、模拟交易和
本机 HTTP 安全边界。模拟通过不代表真实账户兼容或真实到期执行已通过。
已发布页面不会收集 Client Secret；本机设置页由用户本人操作。
