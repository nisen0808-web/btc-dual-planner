本机账户连接 · DERIBIT

让策略页面连接这台电脑

账户密钥只保存在这台 Windows 电脑，由当前 Windows 用户加密保管。策略页面只接收短期配对凭证，不接收账户密钥。请保持电脑和本机服务运行，才能持续处理订单与到期接币。

1配置账户

默认选择测试网。你也可以本人选择主网并输入主网凭据；主网下单会使用真实资金，须明确勾选下单许可，并在策略页面逐笔最终确认。

请使用所选环境的专用子账户，开启账户读取和交易权限，关闭钱包、提现与划转权限。只读 Key 无法卖 PUT。首版支持单币标准保证金，不支持跨币抵押或组合保证金。

保存请求结束后，输入框会清空。密钥不会发送到策略网站，也不会保存在浏览器存储中。

默认关闭下单。保存账户配置不会提交订单；账户、权限与资金仍需核验。

2检查本机状态

账户配置尚未核验
账户环境尚未核验
账户与资金尚未核验
常驻执行服务尚未核验

3授权策略页面连接

点击配对后，下面这个策略网站可以通过本机服务查看账户状态，并按你在策略页面逐次确认的条件请求执行。

配对不等于确认卖 PUT。每次新策略仍需在策略页面检查金额、接币价和到期时间后确认。

撤销配对只会断开网页连接。已确认的策略、PUT 持仓和已提交订单仍由本机执行服务继续处理；如需暂停后续自动动作，请先在策略页面暂停。

电脑休眠、关机或停止本机服务后，到期接币无法保证执行。需要停止自动动作时，先在策略页面暂停；已经提交的订单仍需继续对账。
